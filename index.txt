What is HTTP Header ? => 
  1. metadata => key-value sent along with request and responce

  => caching, authetication, manage state

. Request Header --> from client
. Responce Header --> from server
. Representation Header --> encoding/compression
. Payload Headers --> data

HTTP METHODS => Basic set of operation that can be used to interact with server

. GET => retrieve a resource
. HEAD => No messaage body (responce headers only)
. OPTIONS => what operations are availble
. TRACE => loopback test (get some data)
. DELETE => remove a resource
. PUT => replace a resource
. POST => interact with resource(mostly add)
. PATCH => change part of a resource
